# Liangray Li

I build data-driven web apps, prediction models, and interactive graphics. My projects span Python, React, TypeScript, and WebGL.

## Selected work

| Project | What it demonstrates |
| --- | --- |
| [UFC Elo](https://github.com/PIGJET/ufc-elo) | A full-stack fighter analytics site with division-aware Glicko-2 ratings, matchup predictions, and walk-forward model evaluation. |
| [Portfolio](https://github.com/PIGJET/liangray-portfolio) | A creative-developer portfolio with interactive particle typography and a responsive editorial layout. |
| [ClipForge Pipeline](https://github.com/PIGJET/autoclipnew) | A VOD highlight discovery pipeline combining audience signals, audio peaks, targeted transcription, and an editor review interface. |
| [Endless Roads](https://github.com/PIGJET/driving-game) | A browser driving game with streamed procedural terrain, floating-origin rendering, and custom vehicle physics. |
| [Shinless](https://github.com/PIGJET/running-app) | A client-side running-form analyzer that uses pose landmarks to produce gait metrics and visual overlays. |
| [Neon Raymarcher](https://github.com/PIGJET/neon-raymarcher) | An infinite procedural city rendered in WebGL2 with signed-distance fields and sphere tracing. |

Each repository includes a project overview and instructions for running it locally.
